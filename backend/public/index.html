🚀 Запуск сервера

Проект собран на TypeScript (строгий режим). Скрипты из backend/package.json:
npm install # установка зависимостей npm run build # компиляция TypeScript (src/ → dist/) npm start # запуск продакшен-сервера (node dist/server.js) npm run dev # режим разработки (nodemon + ts-node) npm run start:https# HTTPS-сервер (нужны сертификаты в security/certs)
Порт задаётся переменной окружения PORT (по умолчанию 8080).

📡 Протокол WebSocket: исходящие сообщения (client → server)

1. Присоединиться к лобби
{ "type": "lobby::join", "data": { "personalInfo": { "name": "string", "avatar": "string | undefined" } } }
2. Начать звонок другому пользователю
{ "type": "lobby::initiate-call", "data": { "receiverId": "string" } }
3. Принять звонок
{ "type": "lobby::accept-offer", "data": { "offerId": "string" } }
4. Отклонить звонок
{ "type": "lobby::decline-offer", "data": { "offerId": "string" } }
5. Закончить звонок
{ "type": "call::end", "data": { "callId": "string" } }
6. Поменять online статус
{ "type": "call::online", "data": { "callId": "string", "status": true | false } }
7. Поменять mute статус
{ "type": "call::mute", "data": { "callId": "string", "status": true | false } }
8. Поменять speaking статус
{ "type": "call::speaking", "data": { "callId": "string", "status": true | false } }
9. Отправить текстовое сообщение в звонок
{ "type": "call::send-message", "data": { "callId": "string", "message": "string" } }
10. Начать / остановить демонстрацию экрана
{ "type": "call::start-screen-sharing", "data": { "callId": "string" } } { "type": "call::stop-screen-sharing", "data": { "callId": "string" } }

📥 Входящие уведомления (server → client)

Тип события Когда приходит
me::lobby-joined Подтверждение входа в лобби (с вашим clientId)
all::lobby::joined В лобби присоединился новый участник
all::lobby::client-disconnected Участник отключился
me::call-initiated Звонок создан (ответ инициатору)
me::call-offer Вам поступил входящий звонок (с offerId)
me::call-offer-accepted Ваше предложение звонка принято
me::call-offer-declined Ваше предложение звонка отклонено
all::call::started Звонок начался для всех участников
all::call::ended Звонок завершён
all::call::online-changed Участник сменил online статус
all::call::mute-changed Участник сменил mute статус
all::call::speaking-changed Участник начал/перестал говорить
all::call::new-message Новое текстовое сообщение в звонке
all::call::file-received В звонок загружен файл (с fileId)
all::call::file-deleted Файл удалён из звонка

📁 REST API для файлов (/files)

Файлы передаются вне WebSocket через HTTP (multer). Загрузка привязана к активному звонку параметром callId.
# Загрузка файла (multipart/form-data: file + callId) curl -F "file=@document.pdf" -F "callId=CALL_ID" http://localhost:8080/files/upload # Скачать файл curl -OJ http://localhost:8080/files/download/FILE_ID # Открыть/просмотреть файл (inline) http://localhost:8080/files/view/FILE_ID # Удалить файл curl -X DELETE http://localhost:8080/files/delete/FILE_ID
После успешной загрузки всем участникам звонка рассылается событие all::call::file-received, после удаления — all::call::file-deleted.

🛡️ Безопасность

  • Подключение по WebSocket и запрос /stats защищены авторизацией (AuthMiddleware, токены/секреты из .env);
  • CORS ограничен списком допустимых origin-паттернов из конфига (src/config);
  • Действует rate limiter на входящие WebSocket-сообщения и HTTP запросы;
  • HTTP-заголовки безопасности устанавливает helmet.
⚠️ Внимание: Сервер предназначен для использования в локальной сети. Для продакшена запускайте HTTPS-версию (npm run start:https) с настоящими сертификатами.
